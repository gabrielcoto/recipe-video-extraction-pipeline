# Changelog

## [Unreleased]

- Контракт оставлен на 1.0.0 (совпадает с upstream): бамп общего контракта — решение Виктории Пугач. Расширение единиц (`cup`, `oz`, `lb`) превращено в черновик 1.1.0 (`docs/drafts/`) с готовым текстом issue для upstream; пакет, схема и примеры возвращены к upstream-состоянию.
- Промпт LLM ограничен единицами контракта: «зубчик/ломтик/пачка/банка», в англоязычных видео clove/slice/can/stick → `pcs` + `note`; `cup`/`oz`/`lb` пересчитываются по фиксированным коэффициентам (240 мл / 28,35 г / 453,6 г, округление до целых) с исходной формулировкой в `note`; «стакан» и прочие меры без коэффициента — только `note`. Полнота ингредиентов (включая соль и специи) усилена правилом сверки.
- Селектор качества видео заменён на `bv*+ba`-цепочку с предпочтительным потолком 720p (выше — только если у источника нет вариантов ≤720p вовсе): комбинированный файл YouTube обычно только 360p, а DASH-only источники раньше не скачивались вовсе. Порядок веток закреплён тестом; проверено на движке yt-dlp.
- Тело ошибки API снова `{"code", "message"}` (сломано find-and-replace'ом); форма закреплена тестами.
- Неперехваченные исключения возвращают JSON `500 internal_error` без внутренних деталей; подробности только в логах.
- Отсутствующий ffprobe/ffmpeg теперь `500 media_processing_failed`, а не `400 video_unreadable`.
- Повторы LLM при нарушении схемы видят свой предыдущий ответ (`assistant`-сообщение в истории) — иначе при температуре 0 попытки не отличаются.
- OCR: добавлен порог уверенности `OCR_MIN_CONFIDENCE` (по умолчанию выключен); комментарий о дедупликации приведён в соответствие с кодом.
- Whisper: `WHISPER_LANGUAGE=auto` передаёт `language=None` — настоящий автодетект языка; подчеркнуто отличие от `OUTPUT_LANGUAGE`.
- Транзиторные сбои LLM (сеть, 408/429/502/503/504) повторяются отдельно от повторов схемы: `LLM_NETWORK_RETRIES`, `LLM_RETRY_DELAY_SECONDS`.
- Метаданные платформы без длительности (и мусор в `duration`) — `400 video_unreadable`, а не `502`.
- Двойной вызов yt-dlp для URL оставлен: лимит длительности обязан срабатывать до скачивания, а прямые ссылки из метаданных протухают за минуты.
- Проверка cookies.txt расширена: каталог вместо файла, пустой/JSON/UTF-16 файл, монтирование `:ro` — все случаи дают понятную ошибку до вызова yt-dlp.
- Ошибка yt-dlp показывает хвост stderr (раньше WARNING до ERROR скрывали причину); добавлена `YTDLP_EXTRACTOR_ARGS`.
- Аутентификация yt-dlp против «Sign in to confirm…»: `YTDLP_COOKIES_FILE`, `YTDLP_COOKIES_FROM_BROWSER`, `YTDLP_PLAYER_CLIENT` в обоих вызовах.
- Запечённая Whisper-модель закреплена на `small`; предзагрузка — build-arg `WHISPER_PRELOAD_MODELS`; `WHISPER_MODEL` влияет только на рантайм.
- Node 22 в образе для player-challenge yt-dlp; `yt-dlp[default]>=2026.10.26`.
- Кэши моделей вынесены в именованные тома (`hf-cache`, `paddleocr-cache`, `paddlex-cache`).
- Предзагрузка OCR в full-образе идёт через фабрику `_get_reader` — тот же путь, что в рантайме.
- Исправлен oneDNN-сбой PaddleOCR на части CPU: явный `disable_mkldnn()`; настройка `OCR_ENABLE_MKLDNN`, ограничение ISA `OCR_MAX_CPU_ISA`.
- Закреплена зависимость `av>=11,<19` (PyAV 19 ломает faster-whisper 1.2.1).
- Видео без аудиодорожки не падает: пустая расшифровка, рецепт по тексту с экрана.
- Сбой ffprobe/ffmpeg при извлечении — `media_processing_failed` (проверка кода возврата).
- `OUTPUT_LANGUAGE` задаёт язык рецепта (`auto` — язык видео).
- Настройки вынесены в env (`MAX_VIDEO_SECONDS`, `MAX_UPLOAD_BYTES`, `LLM_TEMPERATURE`, …); сообщения об ошибках показывают настроенные лимиты.
- Документация приведена к состоянию готовой реализации; FAQ переписан; добавлен протокол реальных проверок `docs/real-testing.md`.
- OpenAPI: описаны `empty_file` и `internal_error`.
- Добавлен `scripts/compare_gold.py` — сравнение с ручным эталоном по метрике рубрики (порог 80%); эталоны проверяются контракту в `--validate-only`.
- Добавлен единый устанавливаемый пакет `fropti-core-contracts` 1.0.0 с JSON Schema; режимы чернового и общего контракта удалены — одна модель для API, CLI и примеров.
- Зафиксированы nullable-поля, единицы, шаги и источники рецепта; добавлены импортируемые валидаторы и CLI-проверка JSON; контрактные тесты покрывают все три модуля; `Recipe` разделён с выходными контрактами planner и shopping list.
- Уточнены онбординг, рубрика приёмки и ответственность ревьюеров; MVP ограничен 10–12 часами; добавлены FAQ интеграции, читаемые шаги CI, PR-шаблон и порядок сообщения об уязвимостях.
- Точечные правки: ссылка `[manifest]` в README, оборванный комментарий `requirements-ml.txt`, честная заглушка CLI-теста.
